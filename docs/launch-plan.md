# OpenEmployee Launch Plan

## Phase 0: scaffold

- Repositories, labels, milestones, and issue templates.
- Coordination docs and A2A handoff format.
- Quickstart and roadmap.

## Phase 1: durable MCP employee

- Port/extend typed MCP invocation models.
- Enforce `mcp__<server>__<tool>` Activity boundaries.
- Add auth-ref, claim-check, policy hook, and idempotency contracts.

## Phase 2: computer employee

- Plan OpenManus execution layer.
- Add UI workflow timeline, Activity cards, approval cards, and mock API mode.

## Phase 3: Pipedream communication

- Add Pipedream MCP and Connect connector skeletons.
- Validate SaaS employee examples.

## Phase 4: identity and policy

- Finalize identity spine and policy hooks.
- Plan SPIFFE/SPIRE, OpenFGA/Cedar, and Infisical adapters without hard v0 core dependencies.

## Phase 5: production OSS

- Hardening, docs, observability, release process, and community contribution flow.
